# Installation notes

- Needs node.js version 20 (I had a really old version on my personal machine for some reason).
    - Installing optional components can take a while.
- The npx command pretty much does everything you need.
    - Replace "my-website" with whatever you want your directory to be named.
    - I don't know what all is in the classic template (or what other templates exist).
        - Includes a landing page, which I didn't have in my previous project.
        - Also a blog, which I think is easy to turn off.

## Landing page

- Looks like this is controlled by the following files:
    - \src\pages\index.js
    - \src\components\HomepageFeatures\index.js
- Initial installation also includes a Typescript option. I want to test what that looks like.

## This directory

- New directories make new sidebar categories, new pages are MDX files.
    - This is all very familiar to me.
